二、核心发现
2.1 原算法中的“预估力”是事后评分，不可用于控制
分析发现，required_grip_force（预估力）与实际抓取结果存在异常高的相关性：
· 预估力 < 11N 时，失败率 99.7%
· 预估力 ≥ 11N 时，成功率 99.7%
进一步验证显示，预估力与物体的重量、尺寸、纹理仅存在中等相关性（R² = 0.54），且有近一半的变异无法解释。结合其与成功/失败的完美对应关系，可以判断：预估力是算法在知道抓取结果后反推的评分，而非真实用于控制的指令。
这意味着：
· 预估力不能用于事前预测
· 机器人实际执行时并未参考该值
· 实际施力（三个传感器总和）与预估力无关
2.2 实际施力远大于成功所需的最小值
统计显示：
指标 成功样本 失败样本
最小实际力 26.5 N 36.9 N
平均实际力 130.5 N 144.1 N
最大实际力 230.1 N 247.1 N
所有成功样本的实际施力均 ≥ 26.5N，远大于 11N 的“理论分界线”。说明成功并不依赖精确的力控制，而是靠“大力出奇迹”。
2.3 传感器分配不是失败的主要原因
对比成功与失败案例中三个压力传感器的施力占比，发现：
· 传感器 2 占比在成功组和失败组中的分布几乎一致
· 极端低占比（<0.23）和极端高占比（>0.42）的样本比例在两组中无显著差异
结论：传感器分配不均不是导致抓取失败的主要原因。
2.4 重量是决定成败的最关键因素
使用随机森林对重量、尺寸、纹理三个特征进行建模，预测抓取是否成功：
· 特征重要性：重量（0.55）、尺寸（0.25）、纹理（0.25）
· 测试集准确率：80.2%
· 召回率：88.9%（当阈值设为 0.50 时）
通过调整分类阈值，可以进一步平衡准确率与召回率：
阈值 准确率 召回率 适用场景
0.35 79.4% 94.6% 安全优先，宁可误报
0.40 80.4% 93.6% 推荐
0.50 80.2% 88.9% 平衡
0.60 80.9% 85.7% 精确优先
结论：仅凭重量、尺寸、纹理三个物理特征，即可达到 80% 以上的预测准确率。其中重量是最重要的预测因子。
三、问题定位
综合以上分析，失败案例集中出现在以下特征组合：
重量区间 尺寸区间 纹理 异常低估样本数 失败率
300-500g 0-15mm 0 或 1 165 100%
500-800g 0-15mm 0 或 1 95 100%
结论：算法对 300-500g 的中等重量物体存在系统性低估。这些物体的预估力几乎全部低于 11N，导致被算法判为失败，但实际抓取中机器人用了很大的力（150N 左右），仍然有很高的失败率——说明问题不在力的大小，而在于抓取策略或物体本身的物理特性。
四、优化建议
4.1 数据采集层面
1. 补充 300-500g 重量段的数据，尤其是纹理 0 和纹理 1 的小尺寸物体（0-10mm）
2. 记录抓取姿态信息（抓取点坐标、夹爪开度），这是当前缺失的关键变量
3. 增加失败案例的详细标注（失败原因：滑脱、未抓稳、姿态错误等）
4.2 算法层面
1. 放弃使用当前的 required_grip_force 作为控制指令，它本质上是事后评分
2. 用随机森林模型做前置风险评估：输入重量、尺寸、纹理，输出失败概率
3. 当预测失败概率 > 40% 时，触发预警并调整抓取策略（如降低速度、更换抓取点）
4.3 控制层面
1. 检查机器人是否按算法指令执行。当前数据显示实际施力与预估力完全无关，可能存在控制闭环断裂
2. 考虑引入力控闭环，让实际施力真正跟随算法输出
